# jaw 0.1.0: the spare-number session

Thursday 5 November, the afternoon: every kind of message's live check, in one batch, on the Go engine (jaw-engine, whatsmeow) and the spare number, before Friday's release. It's the design's engine contract suite run live: the demo engine runs it in CI, and this is the Go engine against WhatsApp itself. About three and a half hours, and a few minutes on Friday for S22's second half.

**Where results go.** Each check ends in a **Result** line. Write on it in this file, in `~/src/jaw` (it's on main by Thursday): `pass`, or what was different, with the time from `date +%H:%M`, so its lines can be found in `~/jaw-spare/jawd.log`. Tell the coordinator when you're done: the filled file lands as the session's record, and each failure becomes a task, marked as blocking Friday or not.

**What the demo covers.** Each check's **Demo** line says what `jaw demo`, `jawd --engine demo` and its `--fail` modes already show, so what's left to see here is WhatsApp's side: what whatsmeow hands jawd, and what the phones make of what jaw sends. They're there to compare with, not to run in the session's terminal: `jawd --engine demo` there would write the made-up account into the spare number's folder.

## Before you start

You need two phones: **S**, with the spare number, which the session's jaw links to, and **Y**, your own, the other side of each chat. Your own jaw, linked to Y's account, sees those chats too, as any device of yours does; that changes nothing here.

1. **History to link to.** On S, before linking, make some: a chat with Y holding text, a photo, a video, a voice note, a document, a poll and a reaction; a group "jaw test" with S and Y; and a community with that group in it, or a new one. A chat with photos from a few weeks ago is best, for S18.
2. **A build of main of its own,** so nothing your own jaw runs is rebuilt under it:

   ```sh
   git -C ~/src/jaw fetch origin
   git -C ~/src/jaw worktree add --detach ~/src/jaw-spare origin/main
   cd ~/src/jaw-spare && make release   # target/release/jaw and jawd, target/engine/jaw-engine
   ```

3. **A terminal for the session alone,** where every command reaches the spare number's jawd and never your own:

   ```sh
   export JAW_HOME="$HOME/jaw-spare"
   alias jaw="$HOME/src/jaw-spare/target/release/jaw" jawd="$HOME/src/jaw-spare/target/release/jawd"
   jaw --version          # main's version, the same as jawd --version
   ```

   Your own jawd keeps running on its own folder, untouched. To find the session's processes, by their pids, never by name: `ps -axo pid,command | grep '[j]aw-spare/target'`.
